========================================================
【1】I/Oポート一覧
========================================================

ベースアドレスは BIOS ワークエリア 0006h/0007h
の値（通常 98h）。以下 base=98h として表記する。

┌────┬──────┬──────┐
│ポート│ 書き込み        │ 読み出し        │
├────┼──────┼──────┤
│ 98h  │ VRAMデータ書込  │ VRAMデータ読出  │
│ 99h  │ 2バイト組(下記) │ ステータス S#   │
│ 9Ah  │ パレット書込    │ FFh（機能なし） │
│ 9Bh  │ 間接レジスタ書込│ FFh（機能なし） │
│ 9Ch  │ 割込クリア/Lock │ 割り込み状態    │
└────┴──────┴──────┘
 98h=Port#0, 99h=Port#1, 9Ah=Port#2,
 9Bh=Port#3, 9Ch=Port#4

■ Port#1 の2バイト組プロトコル
1バイト目に値、2バイト目で意味を指定する。
 2バイト目 bit7=1: レジスタ書込。
   bit5-0=レジスタ番号、1バイト目=値。
 2バイト目 bit7=0,bit6=1: VRAM書込用
   アドレス設定。bit5-0=A13-A8。
 2バイト目 bit7=0,bit6=0: VRAM読出用
   アドレス設定。bit5-0=A13-A8。
 どちらの場合も1バイト目=A7-A0。
 1バイト目を書いた後、2バイト目の前に Port#0
 アクセスやポート読み出しをすると組は破棄
 される。Port#3 書込は組に影響しない。

■ VRAMアクセスの要点
・アドレスは18ビット（A17-A0）。下位14ビット
  を2バイト組で、上位 A17-A14 を R#14 で指定。
・書込用設定後の最初の Port#0 書込では
  アドレスは進まない（2回目から進む）。
・折り返し幅はモードで変わる: {M5,M4}=00 の
  系統（G1/T1/MC/G2）または R#8 VR=0 では
  14ビット、互換モードでは17ビット、
  拡張モードでは18ビット。
・R#45 MXC=1 の間、CPUのVRAMアクセスは
  マスクされる（書込無効、読出は FFh）。

■ Port#4（割り込み制御）
 読み出し:
    7             6-3             2     1     0
  ┌──┬───────────┬──┬──┬──┐
  │Lock│          0           │ CI │ LI │ FI │
  └──┴───────────┴──┴──┴──┘
  Lock: LockExtReg（リセット時1）
  CI/LI/FI: コマンド完了/ライン/フレームの
  割り込み要因が発生中なら 1。
 書き込み: bit2/1/0 に 1 を書くと対応する
 割り込みフラグをクリア（0書込は無効）。
 bit7 は LockExtReg への書き込み。

■ LockExtReg と拡張レジスタ
リセット時はロック（1）され、R#20/R#21 への
書き込みは無視される。拡張機能を使う手順:
 1. Port#4 に bit7=0 を書く（ロック解除）
 2. R#21 の V58 を 0 にして拡張モードへ
 3. R#20 などを設定する

■ 2nd VDP（ベース 88h）
2台目の VDP は 88h-8Ch（Port#0-#4 相当）。
ワークエリア 0006h/0007h は内蔵（98h）のまま
なので、88h を直接指定してアクセスする。
2nd の垂直同期割り込みは H.KEYI でも処理が
必要。要因クリアは Port#4（8Ch）書込か
ステータス読み出しで行う。内蔵側と同期が
一致しないことがある点に注意。

========================================================
【2】コントロールレジスタ R#0-R#27
========================================================

書き込み専用。直接指定は Port#1 の2バイト組、
間接指定は R#17 ポインタ経由で Port#3 へ書く。

R#0 Mode0（リセット: IE1=0, M5M4M3=000）
         7-5          4     3     2     1     0
  ┌────────┬──┬──┬──┬──┬──┐
  │       ―       │IE1 │ M5 │ M4 │ M3 │ ― │
  └────────┴──┴──┴──┴──┴──┘
  IE1: ライン割り込み許可（1で許可）
  M5-M3: 画面モード選択（R#1 の M2,M1 と併用）
  書くとライン割り込みフラグがクリアされる

R#1 Mode1（リセット: すべて0）
    7     6     5     4     3     2     1     0
  ┌──┬──┬──┬──┬──┬──┬──┬──┐
  │ ― │ BL │IE0 │ M1 │ M2 │ ― │ SI │MAG │
  └──┴──┴──┴──┴──┴──┴──┴──┘
  BL: 画面表示許可（1で表示、0で消す）
  IE0: フレーム割り込み許可（1で許可）
  M1,M2: 画面モード選択ビット
  SI: スプライトサイズ（0:8x8, 1:16x16）
  MAG: スプライト拡大（1で2倍）

R#8 Mode2（リセット: VR=1, 他は0）
      7-6       5     4     3     2     1     0
  ┌─────┬──┬──┬──┬──┬──┬──┐

R#16 Color Palette Pointer
                        7-0

  ┌───────────────────────┐
  │                   IL7-IL0                    │

R#20 Mode5【V9968追加】（リセット: 0）
    7     6     5     4     3     2     1     0
  ┌──┬──┬──┬──┬──┬──┬──┬──┐
  │S16 │CEIE│FIL │EPAL│SP3 │ILNS│SVNS│ HS │
  └──┴──┴──┴──┴──┴──┴──┴──┘
  S16: モード1/2の1ライン上限を16枚にする
  CEIE: コマンド完了割り込み許可
  FIL: フラットインターレース（2ページを
    上下につなげて1枚の画面として表示）
  EPAL: 拡張パレット（256色, 5bitx3バイト）
  SP3: スプライトモード3を選択
  ILNS: R#19 のライン番号を R#23 の影響を
    受けない絶対位置にする
  SVNS: スプライトを R#23 の影響を受けない
    画面固定位置にする
  HS: 高速モード（基板信号と OR される）
  LockExtReg=1 の間は書き込みが無視される

R#21 Mode6【V9968追加】（リセット: V58=1）
    7     6     5     4     3     2     1     0
  ┌──┬──┬──┬──┬──┬──┬──┬──┐
  │ 0  │ 0  │ 1  │ 1  │ 1  │ 0  │ 1  │V58 │
  └──┴──┴──┴──┴──┴──┴──┴──┘
  bit7-1 は固定値。機能は bit0 の V58 のみ
  V58=1: V9958互換モード（新コマンド無効,
    テーブルベースの A17 は 0 で保持）
  V58=0: 拡張モード（新コマンド有効,
    VRAM 256KB モード）
  1 を書くと5つのテーブルベースの A17 が
  すべて 0 にクリアされる
  LockExtReg=1 の間は書き込みが無視される

R#22, R#24: 未実装（書き込みは無視される）

========================================================
【3】コマンドレジスタ R#32-R#58
========================================================

すべて書き込み専用。パラメータを先に設定し、
最後に R#46 を書くとコマンドが開始する。

  ┌───────────────────────┐
  │                   SX[7:0]                    │
  └───────────────────────┘

            7-4                     3-0
  ┌───────────┬───────────┐
  │          ―          │       SX[11:8]       │
  └───────────┴───────────┘

R#44 Color
                        7-0
  ┌───────────────────────┐
  │                 カラーコード                 │
  └───────────────────────┘
  描画色（HMMV/LMMV/PSET など）。
  HMMC/LMMC/LFMC では CPU 転送データの
  受け口。LMCM 実行中は読み出された画素値

R#45 Argument
    7       6       5     4     3     2     1     0
  ┌──┬────┬──┬──┬──┬──┬──┬──┐
  │FG4 │MXC/XHR │MXD │MXS │DIY │DIX │ EQ │MAJ │
  └──┴────┴──┴──┴──┴──┴──┴──┘
  FG4【拡張】: 1で画面モードによらずコマンド
    が Graphic4 として動作（拡張モードのみ）
  bit6: 互換モードでは MXC、拡張モードでは
    XHR（LRMM で画素を縦長として扱う）
    MXC=1 の間は CPU の VRAM アクセス不可
  MXD/MXS: 転送先/転送元のメモリ選択。
    V9968 では拡張RAM廃止のため VRAM のみ
  DIY: Y方向（0:下, 1:上）
  DIX: X方向（0:右, 1:左）
  EQ: SRCH の一致条件
  MAJ: LINE の長軸（0:X方向, 1:Y方向）

R#51-R#58 Window【V9968追加】（LRMM専用）
 LRMM の転送元参照ウィンドウ（開始点と
 終了点、両端を含む）。内側は転送元から

【4】ステータスレジスタ S#0-S#9
========================================================

すべて読み出し専用。R#15 で番号を指定して
Port#1 を読む。レジスタにより、読むとフラグ
がクリアされるものがある（副作用欄）。

S#0
    7     6     5                4-0
  ┌──┬──┬──┬──────────────┐
  │ F  │ 5S │ C  │            5TH             │
  └──┴──┴──┴──────────────┘
  F: フレーム割り込みフラグ
  5S: 1ライン表示上限を超えた（オーバーマップ）
  C: スプライト衝突フラグ
  5TH: 上限を超えたプレーンの番号（32以上は
    1Fh）。F=1 の間、5S は 0 で返る
  副作用: 読むと F, C, 5S がクリアされる

S#1
      7-6                  5-1                0
  ┌─────┬──────────────┬──┐
  │0（固定） │             ID             │ FH │
  └─────┴──────────────┴──┘
  ID: チップ識別コード。互換モード=00010、
    拡張モード=00011（V9968 判別に使う）
  FH: ライン割り込みフラグ
  副作用: 読むと FH がクリアされる

S#2
    7     6     5     4     3     2     1     0

  └──┴──┴──┴──┴──┴──┴──┴──┘

【5】画面モードと標準VRAMマップ
========================================================

モードは R#0 の M5,M4,M3 と R#1 の M2,M1 で
選択する。Text1 と Multicolor では M3 は
ドントケア。新しい画面モードは追加されて
いない（全12モードは V9958 と同等）。

 モード      M5M4M3M2M1 SCREEN 画面/色
 Graphic1    00000   SC1  32x24パターン/16色
 Text1       00001   SC0(40) 40x24文字/2色
 Multicolor  00010   SC3  64x48ブロック/16色
 Graphic2    00100   SC2  256x192/16色
 Graphic3    01000   SC4  256x192/16色
 Graphic4    01100   SC5  256x212/16色
 Text2       01001   SC0(80) 80x24文字/2色
 Graphic5    10000   SC6  512x212/4色
 Graphic6    10100   SC7  512x212/16色
 Graphic7    11100   SC8  256x212/256色
 G7-YAE      11100   SC10/11 (R#25 YAE+YJK)
 G7-YJK      11100   SC12 (R#25 YJKのみ)

標準配置は MSX-BASIC が SCREEN 文で初期化
したときの配置。アドレスは論理アドレス。
拡張モードでは 20000h-3FFFFh も使えるが、
標準配置は 128KB の範囲内に収まる。

■ Text1（SCREEN 0 WIDTH 40）
 40x24文字（6x8ドット）, 2色, スプライトなし
 パターンネーム   00000h  960B  R#2=00h

  ジェネレータ=文字コードx8+ライン(0-7)

■ Text2（SCREEN 0 WIDTH 80）

 パターンジェネレータ 01000h 2048B R#4=02h
 R#10=00h, R#1=70h, R#7=F4h, R#9 LN=0

 ブリンク 270B まで広がる

========================================================
【6】スプライト
========================================================

 モード1（TMS9918互換）: G1,G2,MC で使用
  32枚, 1ライン4枚（S16=1で16枚）
 モード2（V9938追加）: G3-G7 で使用
  32枚, 1ライン8枚（S16=1で16枚）
 モード3（V9968新設）: R#20 SP3=1 で有効
  G1-G7,MC のすべてで使用可
  64枚, 1ライン16枚
 テキストモードではスプライトは使えない

共通の約束:
・Y座標は「表示ラインの1つ上」を指す
  （ライン0に表示するには Y=255）
・表示打ち切り値: モード1は Y=208,
  モード2/3は Y=216。以降のプレーンは
  表示されない
・プレーン番号が小さいほど優先度が高い
・上限を超えたら S#0 の 5S/5TH で通知
・アトリビュートは1枚4バイト（モード1/2）
・モード2のカラーテーブルは1枚16バイトで、
  アトリビュートのベース bit9 を 0 にした
  位置へ自動配置される（標準配置では
  アトリビュートの 200h 手前）
・R#8 SPD=1 でスプライト表示全体を禁止

モード3の特徴:
・パターンは横16ドットx4ビット、ドットごと
  に色指定（色コード0は透明）
・プレーンごとに拡大/縮小（MGx,MGy）、
  左右反転（RVX）、上下反転（RVY）が可能
・半透明ブレンド（0/25/50/75%）が可能
・パターン配置は常に Graphic4 相当の計算
  （パターンシート形式）。FG4 と組み合わせ
  て他モード表示中でもパターンへ描画できる
・SP3 を有効にすると SCREEN7以上でも VRAM
  物理配置がフラットに戻る。切り替えで
  データの並びが変わる点に注意

========================================================
【7】パレット
========================================================

パレット RAM は 256エントリ x RGB各5ビット。
書き込みは Port#2、番号は R#16 で指定する。

■ EPAL=0（通常形式）: 番号 0-15, 2バイト
 1バイト目: 0 R2 R1 R0 0 B2 B1 B0
 2バイト目: 0 0 0 0 0 G2 G1 G0
 RGB各3ビット。内部では5ビットに拡張して
 格納。1組ごとに番号は [3:0] で進む

■ EPAL=1（拡張形式）: 番号 0-255, 3バイト
 各バイト 5ビット値（000xxxxx）で、
 順に R, G, B。1組ごとに8ビットで進む

■ リセット時の初期値
初期化されるのは先頭16エントリのみで、
V9958 互換の初期カラーになる。16番以降の
初期値は不定。

■ Graphic7（SCREEN8）のスプライト色
EPAL=0 では固定16色（GRB332）で、パレット
セット指定はモード2/3 とも無効（モード3の
半透明ブレンドは有効）。背景と同じ256色
パレットを16色ずつのグループで使う形は
EPAL=1 の場合のみで、グループ先頭色は
透明扱いになる。

========================================================
【8】V9968拡張とGeo3D
========================================================

■ 拡張モード（V58=0）で有効になるもの
・新コマンド LRMM / LFMC / LFMM
・VRAM 256KB（テーブルベースの A17 有効）
・R#45 の FG4 / XHR
・R#25 の SPS
切り替えは LockExtReg 解除が前提（【1】）。

■ 主な拡張ビット早見
 V58 (R#21.0): 互換/拡張モード切替
 S16 (R#20.7): モード1/2の1ライン上限16枚
 SPS (R#25.7): 優先度の循環変化
 SP3 (R#20.3): スプライトモード3
 EPAL(R#20.4): 拡張パレット
 FIL (R#20.5): フラットインターレース
 SVNS(R#20.1): スプライト画面固定
 ILNS(R#20.2): ライン番号を絶対位置に
 CEIE(R#20.6): コマンド完了割り込み
 HS  (R#20.0): 高速モード

■ Geo3D（3Dエンジン）の入口
Geo3D のレジスタはインデックス/データ方式。
ポートベースはカートリッジの DIP スイッチ
で 88h系 / 98h系から選ぶ。
 88h系: インデックス 8Dh, データ 8Fh
 98h系: インデックス 9Dh, データ 9Fh
書き込み: インデックスポートにレジスタ番号
を書き、データポートに値を書く。16ビット値
は下位、上位の順に連続インデックスへ。
読み出し: 番号を書くとデータポートから
値が読める。詳細は説明書 第9章を参照。
